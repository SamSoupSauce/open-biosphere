## 1. Subsystem Overview & Agentic Operating Principles

Stage 2 upgrades the BCA Packaging Engine into a fully autonomous cyber-physical production cell. By implementing the **Controller-Node-Tool (CNT)** hierarchical edge standard, the machine operates as an autonomous node within the multi-agent agricultural facility.

A high-level central agent running on the Central Controller (Raspberry Pi 5 or local Linux host) orchestrates container sizing, production quotas, and quality inspection. Dynamic 4-way stepper gate plates ([`PART-FAB-DIE-GATE-4WAY`](/open-biosphere/parts/part-custom-die-gate-4way/)) automatically resize the extrusion profile without tooling swap downtime. A high-speed flying wire shear carriage ([`PART-FAB-SHEAR-CARRIAGE-WIRE`](/open-biosphere/parts/part-custom-shear-carriage-wire/)) cleanly slices containers to programmed height, and an S-beam 200 kg load cell provides real-time compaction density feedback to prevent voids or structural porosity.

## 6. Autonomous Multi-Agent Production Protocol

```text
Central Facility Agent (Controller)
       │
       │ (1) Request: "Produce 12x Seedling Pots (80x80x100mm)"
       ▼
ESP32-S3 Machine Node
  ├── 1. Move Die Steppers: X=80mm, Y=80mm (Aperture Set)
  ├── 2. Ramp Barrel: Zone 1=150°C, Zone 2=175°C
  ├── 3. Engage Breaker & Ram: Monitor Load Cell (Target: 850N Compaction)
  └── 4. Trigger Cutoff Servo at Z=100mm
       │
       │ (2) Telemetry: "Container Ready at Pickup Datum"
       ▼
Ground AGV / Overhead Gantry
  └── Transports finished pots to Nursery Racks
```

1. **Demand-Driven Sizing:** The crop planning agent determines whether the nursery requires small seedling pots (60 × 60 mm) or bulk produce crates (180 × 180 mm) and issues commands over the local REST/WebSocket API.
2. **Dynamic Compaction Regulation:** As aggregate density naturally varies between grog batches, the ESP32-C3 Tool Node monitors compaction force via the load cell in real time. If density drops below 1.85 g/cm³, ram speed slows to allow higher consolidation pressure.
3. **Automated Cutoff & Ejection:** Optical distance sensors track extrusion length; once the target height is reached, the servo shears the wall profile and the bottom pusher tilts the rigid container onto the radiant conveyor belt.

## 7. Pre-Flight Verification Checklist

* [ ] 4-Way stepper die gates home reliably against optical limit switches with $\pm 0.1$ mm repeatability.
* [ ] 200 kg S-beam load cell calibrated with zero drift over a 2-hour thermal cycle.
* [ ] Flying wire shear completes cutting pass in &lt; 250 ms with clean edge parting.
* [ ] Hardware deadman watchdog trips in &lt; 250 ms on packet loss, immediately de-energizing stepper drivers.
* [ ] Central controller agent can query telemetry and initiate complete container production cycle autonomously.
