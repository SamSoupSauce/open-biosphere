## 5. BLE Peripheral Operation & Runbook

### 5.1 BLE Service & Gating GATT Map
* **Service UUID:** `0000FFE0-0000-1000-8000-00805F9B34FB`
* **Telemetry Data (`0xFFE1`, Notify):** `[pH_val: float32, EC_us_cm: uint16, Water_temp_c: float32, CO2_ppm: uint16]`
* **Dosing Pulse Command (`0xFFE2`, Write):** `[Channel: uint8 (0-5), Volume_mL: uint16, Duration_ms: uint32]`
* **CO₂ Pulse Gate (`0xFFE3`, Write):** `[Duration_sec: uint16]`

### 5.2 Commissioning Steps
1. **Backplane Plumbing:** Connect food-grade 4mm ID silicone tubing from nutrient concentrate carboys through the peristaltic rollers to the Central Basin delivery manifold.
2. **CO₂ Line Purge:** Connect 100% beverage-grade CO₂ tank through a two-stage regulator (set to 15 PSI) to the brass solenoid. Verify leak-free seal using soapy water.
3. **BLE Integration:** Pair the central automation controller or Flutter mobile app. Verify each peristaltic channel dispenses calibrated volumes within ±2% tolerance.
