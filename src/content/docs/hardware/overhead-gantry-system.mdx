## 1. Subsystem Architecture

The **2-Axis Overhead Gantry** spans the length ($Y = 6,096$ mm) and width ($X = 3,048$ mm) of the pool enclosure at an elevation of $Z = 1,200$ mm. It provides rigid, high-precision positioning for macro optical cameras, micro-tweezer actuators (for saffron), and lateral shears (for purslane).

---

## 2. Technical Specifications

| Parameter | Specification |
| :--- | :--- |
| **Drive Mechanism** | GT2 9mm steel-reinforced timing belts with NEMA 23 closed-loop steppers |
| **Linear Guide** | Dual 2040 V-slot aluminum extrusions with polyoxymethylene (POM) wheels |
| **Repeatability** | $\pm 0.15$ mm across the entire 20 × 10 ft envelope |
| **Payload Rating** | Up to 8.5 kg toolhead payload |
| **Toolhead Mount** | Magnetic kinematic quick-swap mount for interchangeable end-effectors |
| **Controller** | BTT Octopus Pro (STM32H723) running Klipper firmware via CAN bus |

---

## 3. Interchangeable Toolheads

- **Micro-Tweezer**: Silicone-tipped precision gripper for harvesting saffron stigmas.
- **Rotary Shears**: High-speed reciprocating blades for cut-and-come-again purslane and sorrel harvesting.
- **Multispectral Scanner**: 12-band spectral line camera generating full-canopy health heatmaps daily.
