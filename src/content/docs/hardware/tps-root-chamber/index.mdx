## 3. Modular Canopy Decoupling: Universal Solar Roof Standard (RFC-0009)

In accordance with [RFC-0009: Universal Helical Shutter Solar Roof Standard](/open-biosphere/rfcs/rfc-0009-helical-shutter-solar-roof/), the TPS Root-Zone Chamber decouples subterranean root misting from canopy solar irradiation:
* **Canopy PAR Delivery:** Diffuse, high-intensity natural sunlight is bounced omnidirectionally across the upper vine trellis via the inverted 45° specular pyramid deflector (`PART-OPT-CONE-DIFFUSER-PYRAMID`).
* **Complete Root Darkness:** Because all solar collection and shutter attenuation occur inside the central vertical tower, the lower aeroponic root tank maintains 100% darkness (&lt; 0.05 lux), completely preventing tuber greening and toxic solanine synthesis.
* **Thermal Regulation:** When ambient greenhouse temps spike, the rotary shutter occludes up to 95% of solar infrared gain, protecting delicate potato root hair transpirational health.

### Step-by-Step Zero-Waste Conversion Roadmap

#### Path 1: Base Machine → Add-On 1 (Motorized Misting Chamber)
1. Mount the 24V 120 PSI booster pump to the rear wall of the HDPE tub.
2. Install the 1/4" nylon tubing and six brass anti-drip nozzles inside the tub at $Z = 300$ mm height.
3. Mount the Two-Control junction box on the front rail, pair the Flutter Companion App BLE Virtual Panel, and plug in the 24V desktop power supply. The manual garden wand pass-through grommets remain permanently accessible.

#### Path 2: Add-On 1 → Add-On 2 (Autonomous Edge CNT Production Cell)
1. Mount the Root Chamber Node (ESP32-S3 + OLED + Button) and modular ESP32-C3 Tools inside the IP65 enclosure.
2. Connect `DEV_PUMP_RELAY` to the booster pump and 24V fast-bleed solenoid in parallel with the manual dial timer.
3. Mount the MLX90614 infrared root sensor in the tub lid and wire to `DEV_ROOT_TELE`.
4. Install dual optical liquid level sensors in the suction line manifold.
5. Provision the Root Chamber Node with Central Controller ID via mobile app BLE, and verify 250ms hardware watchdog trips immediately upon signal loss.
