## 1. Component Overview & Architectural Role

Overlapping tool steel die gate plates actuated by independent stepper lead screws for dynamic continuous container width and depth adjustment.

Ground tool steel die gate assembly comprising four overlapping precision sliding plates. Actuated by independent lead screws to vary extruded wall profile dimensions from 60x60mm up to 180x180mm without breaking machine vacuum or thermal hold.
