**Open Biosphere** is an umbrella open-hardware project and research platform for automated closed agriculture. Rather than a single monolithic apparatus, it is designed as a **suite of smaller, modular machines** built from common or easily ordered parts (COTS).

Each machine fulfills an autonomous homesteading, farming, or off-grid function on its own—and all machines interlock seamlessly into a **Master Biosphere Assembly** within a standardized ~20x10 ft footprint (~200 sq ft, 4.5 ft vertical clearance, ~6,000-gallon pool envelope).

## 3. Controller-Node-Tool (CNT) Hierarchical Edge Architecture

Under [RFC-0004](/rfcs/rfc-0004-controller-node-tool) and [RFC-0006](/rfcs/rfc-0006-agnostic-controller-runtime), the biosphere decouples heavy neural compute from edge electro-mechanics through a 3-tier hierarchy:

![Controller-Node-Tool (CNT) Hierarchical Edge Architecture](/open-biosphere/blueprints/cnt-edge-architecture.svg)

1. **The Controller (Central Brain)**: Under [RFC-0006](/rfcs/rfc-0006-agnostic-controller-runtime), the Controller is defined strictly as a portable, hardware-agnostic software runtime (`biosphere-core`) running on any Linux (ARM64/x86_64) or macOS host (e.g. Raspberry Pi 4/5, repurposed x86 mini-PCs, thin clients, or laptops). It hosts an isolated Wi-Fi AP (`POTFRM-<CLUSTER_ID>` on `192.168.42.0/24`), executes local neural reasoning via `llama-cpp-python` with native hardware acceleration, and coordinates multi-agent schedules over secure WebSocket (`ws://192.168.42.1:8443/register`).
2. **The Node (Machine Subsystem)**: Exactly one per physical machine frame (ESP32-S3 with PSRAM). Hosts an OLED status display (`[NODE: <NAME> | LINK -> CTRL_ID]`). Under [RFC-0005](/rfcs/rfc-0005-hardware-interlocks-ble-virtual-panel), physical control panels are banned: the enclosure carries strictly an inline DC power switch and a recessed SD recovery button. The operator provisions the Node and performs manual jogging via the Flutter companion app over local BLE.
3. **The Tools (Actuators & Sensors)**: Minimalist micro-controllers (ESP32-C3 / Xiao) dedicated 1:1 to single motors, drivers, or sensor clusters. Each Tool features a micro OLED status display and a **250ms hardware deadman watchdog** that cuts power or snaps valves closed if communication to its Node is lost.

## 5. Closed-Loop Nutrient Recycling Kinetics

The fluidic loop is designed around nitrogen cascading between machines:
1. **Bio-Digestion**: Organic waste and spent root matter are digested into bioavailable ammonium and nitrate ions.
2. **High-EC Consumers**: The concentrated effluent is first routed through perimeter NFT gutters (purslane, peppers, wasabi) requiring EC 1.8–2.4 mS/cm.
3. **Biological Polishing Filter**: Drain runoff cascades into the central basin where floating *Wolffia globosa* scavenges residual nitrates and phosphorus, operating as a rapid biological filter (target EC 1.2–1.5 mS/cm).
4. **Aeroponic Root Sumps**: Polished water is pressurized through 30–50μm misters directly onto suspended True Potato Seed (TPS) root systems before returning to the main sump.
