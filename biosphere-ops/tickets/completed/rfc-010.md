# [RFC-0010 / DOCS-002] Stepwise Reverse-Deconstructed Blueprint Standard

## 1. Executive Summary & Problem Statement
A single static blueprint showing only the fully assembled tier leaves builders guessing about interior fastener access, component layering, sub-assembly order, and internal tolerances. Standard CAD exploded views often explode parts radially into empty space without illustrating the actual physical order of assembly or tool clearances.

RFC-0010 mandates that **every machine stage (`stage-0.md`, `stage-1.md`, `stage-2.md`) must feature a stepwise sequence of vector blueprints (`.svg`)**. The visual protocol begins with the fully integrated stage assembly and strips away exactly one discrete mechanical/electrical layer per step in reverse order (or builds upward sequentially 1:1), directly paired with the corresponding procedural instructions.

---

## 2. Structural & Architectural Directives

### 2.1 The "1:1 Blueprint-to-Step" Invariant
* Every procedural assembly step (`### Step X.Y`) in Part 5 of a stage manual must have a dedicated, matching visual blueprint:
  `hardware/<machine-slug>/assets/stage-<N>-step-<Y>.svg`.
* Generic placeholder diagrams, duplicate overview diagrams, or text-only assembly steps are strictly prohibited.
* If an assembly procedure has 5 sequential steps, it must contain exactly 5 distinct stepwise vector diagrams plus the master stage elevation overview.

### 2.2 Visual Deconstruction Order & Orientation
* **Orientation Anchor:** All stepwise SVGs for a given machine must preserve an identical viewing perspective (standard isometric, side elevation, or cross-section) and reference the canonical spatial datum ($Z=0.00$ at coping baseline).
* **Stepwise Delta Highlighting:**
  * Active step components (parts being installed, bolted, or torqued in the current step) must be rendered in high-contrast accent stroke/fill.
  * Previously installed structural foundations must be rendered in muted, low-contrast hairline outlines.
  * Unassembled layers must not appear until their respective step.
* **Reverse Inspection Utility:** The sequence must allow a builder to visually deconstruct the machine layer-by-layer to troubleshoot jams, access internal fasteners, or perform retrofits.

## 4. Markdown Integration Pattern (`stage-X.md`)

Each step block in Part 5 of the standardized stage document must pair its instructional breakdown directly with its isolated blueprint:

```markdown
### Step 1.2: Wedge-Wire Screen Installation

![Step 1.2 Mechanical Alignment](./assets/stage-0/step-2-wedge-wire-mount.svg)

1. **Alignment:** Seat the 316L wedge-wire screen (150µm slot, 300mm x 400mm) against the internal side flanges at an exact 38° decline.
2. **Gasket Seating:** Lay 3mm EPDM closed-cell rubber sealing strips along the perimeter channel to prevent frond blow-by.
3. **Clamping:** Secure the screen using four M4 thumb-screws through the clamping rails. Torque finger-tight (approx. 0.8 N·m) to prevent gasket over-compression.

```
