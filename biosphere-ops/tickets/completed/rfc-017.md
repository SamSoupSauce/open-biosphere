## 1. Problem Statement & Audit Findings

An inspection of custom fabricated parts in the Open Biosphere parts registry revealed critical procedural geometry corruption, boolean operation dropouts, inverted winding orders, and zero-thickness degenerate topologies:

* **Missing Features & Boolean Failure (`PART-FAB-JUNCTION-MANIFOLD-4WAY`):**
  * *Symptom:* The model rendered as a plain beveled monolithic block (44 vertices, 44 faces).
  * *Root Cause:* The 3 metering input ports and 1 discharge output bore were either omitted during feature generation or silently discarded during a non-manifold constructive solid geometry (CSG) difference pass.
* **Degenerate Normals & Mesh Mangling (`PART-FAB-LINKAGE-SERVO-DUAL-YOKE`):**
  * *Symptom:* Fragmented, twisted polygonal geometry with inverted and chaotic surface shading.
  * *Root Cause:* Inconsistent polygon vertex winding (mixed counter-clockwise and clockwise definitions), unindexed intersecting self-faces, and non-planar quad triangulation creating folded facet errors.
* **Canonical Benchmark (`PART-FAB-AUGER-PETG-50P`):**
  * *Status:* The continuous flight auger (195 vertices / 384 faces) exhibits clean continuous normals, closed manifolds, and predictable lighting gradients. It establishes the baseline standard for procedural mesh density and smoothness.
* **Zero-Thickness Shell & Missing/Inverted Normals (`PART-FAB-PERCH-CONICAL-DOCK`):**
  * *Symptom:* Solid render exhibited half-culled backfaces (open-shell void); wireframe mode revealed a single-walled conical surface with zero volumetric wall thickness ($t = 0\text{ mm}$) and inward-facing vertex normals causing backface culling dropouts.

## 2. Geometric Requirements & Remediations

```text
+---------------------------------------------------------------------------------+
|                       PROCEDURAL CAD PIPELINE REMEDIATION                       |
|                                                                                 |
|  [Part: Manifold Junction]  --> Inject Barbs / Threaded Bosses + Through-Bore   |
|  [Part: Servo Dual-Yoke]    --> Enforce Manifold Yoke Clearance + Rewind Loops  |
|  [Part: Conical Dock Perch] --> Apply Wall Offset (t >= 2.5mm) + Outward Normals|
+---------------------------------------------------------------------------------+
```

### 2.1. `PART-FAB-JUNCTION-MANIFOLD-4WAY`
* **Port Topology:** Explicit geometry must represent the physical fluid path:
  * 3× Top/Side Input Ports (push-to-connect barb or $1/4''$ NPT thread bosses) with cylindrical recesses.
  * 1× Main Axial Outflow Port with countersunk bore.
* **CSG Guardrails:** If subtraction operations are used, tool solids must extend $+0.1\text{ mm}$ past target faces to eliminate zero-thickness coplanar intersection artifacts before export.

### 2.2. `PART-FAB-LINKAGE-SERVO-DUAL-YOKE`
* **Mesh Re-Topology:** Re-derive the linkage from a unified skeletal extrusion (dual clevis/yoke ends connected via a structural web).
* **Winding Order:** Guarantee strict CCW (counter-clockwise) index ordering for all exterior facing polygons. All co-planar triangles must share common edge directions.

### 2.3. `PART-FAB-PERCH-CONICAL-DOCK`
* **Shell Solidification:** A zero-thickness surface is non-physical and invalid for 3D printing. A wall offset of at least $2.5\text{ mm}$ (interior funnel wall to exterior mounting sleeve) must be extruded to form a closed, watertight 2-manifold solid.
* **Double-Sided Rendering vs. True Geometry:** While the viewer material must default to `THREE.DoubleSide` for fault tolerance, geometry files (`model.gltf`) must pass manifold tests without relying on double-sided shader tricks.

## 4. Acceptance Criteria & CI Linting

Every model committed to `parts/` must pass an automated headless validation check (`npm run test:models`):
1. **Volume Test:** Calculated bounding envelope in all 3 axes must be $\ge 1.0\text{ mm}$ (no flat 2D planes passed off as 3D stock).
2. **Manifold Check:** Every edge must connect to exactly two faces. Zero open boundaries or non-manifold edges.
3. **Face Normal Alignment:** $\vec{n} \cdot (\vec{v}_i - \vec{c}) \ge 0$ across convex hulls, preventing inverted inward-pointing face cones.
4. **Visual Pass:** Ports, mounting bores, and fluid passages on custom manifolds must be visually identifiable in the interactive viewport under standard lighting.
